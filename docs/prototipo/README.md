# Identidade Visual e Protótipos

Este documento apresenta a proposta visual, a tipografia, a paleta de cores e os protótipos de alta fidelidade das telas essenciais do sistema **MoneyFlow**.

## 1. Nome e Proposta Visual
**Nome:** MoneyFlow
A identidade visual foi concebida com um padrão moderno de *fintech*: interface limpa, amplo uso de espaço em branco (white space), cantos arredondados e *cards* com sombras leves. O tema claro foi escolhido para evitar sobrecarga cognitiva e facilitar a leitura diária de gráficos e dados financeiros.

## 2. Paleta de Cores
A paleta utiliza cores semânticas para promover uma leitura intuitiva dos números:
*   🔵 **Cor Primária (Identidade/Ações):** Azul-índigo.
*   🟢 **Cor de Sucesso (Receitas/Ganhos):** Verde.
*   🔴 **Cor de Alerta (Despesas/Perdas):** Vermelho.
*   ⚪ **Cores Neutras (Fundos/Textos):** Variações de cinza.

## 3. Tipografia
Para garantir a melhor legibilidade de valores monetários e dados tabulares, optamos por uma tipografia sem serifa (Sans-serif) com hierarquia estruturada:
